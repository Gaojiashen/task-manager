# 多邮箱与本地邮件

应用按绑定方式接入邮箱，不按品牌分类。顶部“邮箱”打开工作台；旧版已有配置自动保留，不必重新输入。

## 添加和连接

点击“添加邮箱”，选择一种绑定方式。每个绑定独立保存，可以添加多个IMAP和多个Microsoft 365邮箱，互不替换。

IMAP：在服务商处开启IMAP并取得客户端授权码（若要求）。填写完整邮箱、服务器主机名、端口、安全方式，用户名留空使用邮箱。TLS通常993、强制STARTTLS通常143，以服务商文档为准。填授权码或服务商允许的密码，点击“保存连接设置”，再点击“连接此邮箱”。仅验证成功才显示已连接。相同连接参数留空口令可保留原凭据；更换身份后必须重填。应用验证证书，不提供明文认证。只支持OAuth的服务器不能用普通密码接入。

Microsoft 365：适用于工作或学校组织账号。按[outlook-setup.md](outlook-setup.md)配置公开客户端ID，保存后连接，在系统浏览器完成授权。学校可能要求管理员批准。应用只申请读取权限，不收邮箱密码。

主动断开会清除该绑定凭据，不删除已存邮件或待办；IMAP再次连接需填回授权码。新凭据加密在data/mail-accounts/<绑定ID>/，旧配置仍引用原位置。跨设备无法解密时先完整备份data，再重配登录，勿删除tasks.sqlite。

## 选择读取范围

每个账号点“设置”，在右侧加载文件夹，可多选并包含子目录；不选默认收件箱。文件夹窗格固定最小高度，独立滚动。可按最近N天、指定日期起、起止日期、发件人、主题、邮箱未读筛选。点击“应用这些读取条件”后用于后续导入。

回到工作台，勾选要导入的账号，点击“导入所选邮箱”。使用各自默认范围；新账号默认最近7天，包含今天，按本机收件日期筛选。默认“仅导入未保存的邮件”，已缓存的邮件跳过正文下载；取消此项会重新获取，原文变化后清除最新分析标记，已有待办不变。读取不会改变服务器已读状态。

每个账号最多返回200封匹配邮件，达到上限需缩小日期范围继续。按目录收集后排序，不保证跨目录全局最新200封。IMAP身份为目录+UIDVALIDITY+UID，移动或复制可能产生新身份。

## 预设、排除与已知发件人

账号设置中可给当前条件命名，保存多套读取预设。选择预设会填入条件；点“应用这些读取条件”后用于后续导入。包含文字与不包含文字同时生效，忽略大小写；多发件人包含列表任一匹配即可，排除列表任一匹配则跳过。导入后保存已知发件人，可勾选或按行自行添加。导入区显示账号当前实际日期范围。

## 本地归档和删除

正文保存在data/mail.sqlite，离线可查看，不保存附件。可创建本地文件夹、批量移动；移除文件夹后邮件回到未归类。删除本地邮件需确认，会删除正文行，保留独立的导入／分析收据及已知发件人。后续同步即使关闭“仅导入未保存”也不会恢复已删除邮件。去重优先使用绑定及邮箱稳定ID，不仅依赖可能重名的标题或日期；IMAP移动、复制或UIDVALIDITY重置可能形成新身份。

AI产出和会话独立保留，可能仍引用此前分析的文字。删除本地邮件不删除这些产出、已创建待办或服务器邮件。若不需要某个对话，可在AI历史删除对话记录；已生成草稿及待办保留。SQLite启用secure_delete用于清理删除行，不承诺对已有备份或SSD物理残留做安全擦除。

## 可暂停的后台处理

导入与分析启动后立即返回后台任务进度。点击“暂停”中止当前等待并保留检查点；点击“继续处理”接着执行。收起邮箱窗口后仍可操作待办。完成后底角提供返回入口，系统支持时有原生提醒；应用退出时任务保留，下次主动继续。当前被中止但已经送达云端的请求仍可能计费。

已完成导入不会重复下载正文；失败导入可再次发起并只补未保存邮件。AI默认每封邮件独立请求，仅超长单封分段，长度报错时缩小当前批，限流／网络问题有限重试，失败后继续不会重发成功批次。单任务最多1000封、12MiB原文、2000段，每批最多100草稿；段间不自动进行完整关联推理，可在会话中继续要求汇总。邮件全部分段成功才记为已分析，不把部分成功伪装成完整分析。

## AI对话与本地记忆

“AI整理”或邮箱里的“AI对话历史”可查看每轮用户输入、AI分析、时间和待办草稿；点击审核后才保存为待办。没有待办的总结也保存记录。邮件只有未分析／已分析两种状态，与服务器未读及保存待办分开。

可以新建文字对话，或返回原会话追问，不必再次复制邮件。后续请求带该会话的历史，较长历史用保存的摘要压缩上下文，完整对话日志仍在本机。不是跨所有会话的全局记忆，也不会训练模型。邮件导入和打开正文不自动发送AI，主动分析或发送对话才调用设置中的服务。DeepSeek官方接口使用兼容JSON返回，并以非思考模式处理，减少长等待；所有服务结果都仍需用户核对。

对话、检查点和摘要存data/mail-operations.sqlite，正文、导入收据、预设和归档在mail.sqlite。均为本地明文数据；凭据保持系统加密。JSON待办备份不包含这些内容，退出整个应用后完整备份data。

## 备份与排错

JSON待办备份不含邮件、分析历史或登录配置。退出整个应用后，完整备份data文件夹可同时保留邮件库；登录凭据在其他Windows账号／设备上可能需要重配。

连接失败先核对服务器、加密方式、授权码、服务商访问开关，不关闭证书验证。部分邮件导入失败会列出账号提示，已成功的仍保留；缩小范围再试不会重复保存。过大的邮件请在原邮箱客户端查看。


## 逐封分析与提示确认（当前）

批量勾选只表示依次处理，不把不同邮件拼到同次请求。程序直接把来源绑定为这封邮件，分段来源也相同；待办备注提供本地原文入口。旧记录若只有批次标识，会先按备注中的完整邮件标题唯一匹配，否则明确列出批次候选。已删除正文不重导。

完成提示的点击／关闭状态保存在本机，重开界面不重复提示。升级前已有的完成提示不再补弹，任务与对话记录仍可查看。旧版未完成的多邮件合并计划不会继续混合发送，需要重新选择邮件开始逐封分析。

导入区展示按当前生效条件匹配的预设名称。选择已保存预设可修改条件或名称并点“保存修改”；“新建预设”会进入独立编辑，点“保存新预设”不会改动旧项。应用读取条件仍是独立操作。AI要求及分析按钮恢复为最下方独立窗格。
