# 学校 Outlook 首次连接

Task Manager 使用微软官方 MSAL 登录和 Microsoft Graph 读取邮箱。用户通过系统浏览器完成学校登录及多因素验证。应用不会要求邮箱密码或客户端密钥；登录缓存使用 Windows 系统加密，保存在应用 data 中。

## 一次性注册应用

当前源码不含公共注册的微软应用标识，需先注册属于自己的应用。应用程序（客户端）ID 是公开标识，不是密钥。

1. 在浏览器打开 https://entra.microsoft.com ，使用有应用注册权限的账号登录。
2. 进入“标识 → 应用程序 → 应用注册”，选择“新注册”，名称可填 Task Manager。
3. 支持的账户类型选择“任何组织目录中的账户（多租户）”，用于学校或工作 Microsoft 365 邮箱。
4. 注册后进入“身份验证 → 添加平台 → 移动和桌面应用程序”，添加重定向 URI `http://localhost`。这是本机接收登录结果的临时回调，不是部署公网服务器。
5. 在“API 权限 → 添加权限 → Microsoft Graph → 委托的权限”添加 `Mail.Read`。此功能不需要发送、修改邮件权限，也不需要创建客户端密码。
6. 返回“概述”，复制“应用程序（客户端）ID”，在应用“邮箱 → 首次连接设置”中填写并保存。
7. 点击连接学校 Outlook，在系统浏览器选择学校账号、完成登录和授权；成功后返回应用查看邮箱与文件夹。

菜单名称可能随管理中心语言稍有差别。没有注册权限时，请由允许注册的开发者账号注册多租户应用，或联系学校管理员。学校若要求管理员批准第三方应用，应由管理员审核后授权；不能通过更换前端或粘贴密码绕过学校策略。

## 使用

登录后查看顶层文件夹，展开可读取子文件夹，按需多选并选择是否包含子文件夹。未选择时默认收件箱。筛选支持最近 N 天、指定收件日期之后、起止日期、发件人、主题关键词及仅未读；“保存默认条件”按账户保存，临时读取不修改默认条件。

最近 N 天包含今天并滚动计算；指定起止日期按本机时区计算，结束日包含整天。读取最多显示 200 封匹配邮件，达到限制时给出提示，请缩小范围再读。查看正文是纯文本，不加载邮件里的远程图片或执行 HTML。

点击单封邮件的 AI 整理才将该封正文发送给设置中的 AI 服务。单次正文连同主题、发件人、时间最多 20000 字符，超长时明确提示，不能静默截断。生成后进入待办草稿，用户可选择、修改、确认保存；备注带邮件来源。保存一封邮件的部分草稿也会把该封邮件记为已处理。重复读取可查看，但不能再次直接生成，防重记录在本机数据库中；原有 JSON 备份不包含草稿确认记录，恢复 JSON 备份后这些处理标记不会恢复。

断开连接会清除本机登录缓存，不删除已有待办；重新连接同一账户会恢复该账户保存的筛选。数据迁移到另一台机器后，系统加密缓存可能无法解密。若因此无法进入邮箱配置，请先完整备份 data，再删除其中的 outlook-auth.bin 以重置邮箱连接，之后重新配置与登录；待办保存在 tasks.sqlite 中，不要删除数据库。此操作会清除该缓存中的默认筛选。本指引仅对应 Microsoft 365 浏览器授权方式。允许IMAP授权码／密码的服务器可使用应用中的另一绑定方式，见[通用绑定指引](mail-setup.md)。

## 常见问题

- 提示应用标识无效：核对客户端 ID 是否完整，应用是否按组织账户注册。
- 提示重定向不匹配：核对桌面平台配置中的 `http://localhost`。
- 提示需管理员批准或读取被拒绝：联系学校管理员审核委托的 Mail.Read 权限及该应用；本地程序不能自行解除。
- 登录失效：重新连接学校 Outlook，不需要删除待办数据。
- 未看到某个文件夹：展开父文件夹；当前只列普通非隐藏文件夹，不读取共享邮箱或本地 PST。
